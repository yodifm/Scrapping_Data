🛍️ E-Commerce Product Scraping Dashboard | Python x Power BI Project

This project is an E-Commerce Product Scraping Dashboard built using Python for data collection and Microsoft Power BI for visualization. It’s designed to help users extract, analyze, and visualize key marketplace insights in an automated and efficient way. 💡🐍

✨ Data Collection (Python Web Scraping)
Using Python, product data was scraped directly from an e-commerce platform to gather important attributes, including:

Product Name

Price

Quantity Sold

Store Name

Store Location

The scraping process ensures real-time and accurate data collection, enabling dynamic analysis of market trends and store performance.

📊 Data Visualization (Power BI Dashboard)
Once the data was cleaned and structured, it was imported into Power BI to create an interactive dashboard that provides clear business insights. The dashboard includes:

Total Stores

Total Sold Items

Total Sales Amount (Revenue)

🗺️ A map visualization displays which store locations contribute most to sales—helping identify geographical patterns and top-performing areas.

🔍 Multiple filters allow users to explore the data by product category, store, or location, enabling a customized and deep-dive analysis of the e-commerce landscape.

💰 A sales insight section highlights revenue distribution across different stores, supporting better understanding of product performance and competitive positioning.

💡 This project demonstrates how combining Python for data extraction and Power BI for analytics can transform raw web data into actionable insights—empowering better business decisions in the digital marketplace.
